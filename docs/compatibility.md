# Compatibility status

This table is the source of truth for claims about compatibility with DeepSeek Harness commit `47f943859bef60e4160492346772ded9b24f765a`. Status values are:

- `unresearched`: upstream behavior has not been studied in enough detail;
- `planned`: upstream behavior and a Rust design exist, but implementation does not;
- `partial`: only part of the behavior is implemented;
- `compatible`: deterministic comparison tests support the claim;
- `intentional-difference`: the difference, reason, impact, and tests are recorded.

The v0.1 release gate covers rows in the shipped Phase 0–9 product scope. Rows
whose area begins with `Post-v0.1` deliberately track broader hardening goals;
they remain honest `partial` work without being advertised as v0.1 behavior.
