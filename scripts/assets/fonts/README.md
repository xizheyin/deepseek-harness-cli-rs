# Screenshot font

The Phase 9 terminal screenshot renderer uses JetBrains Mono 2.304 from the
official [`JetBrains/JetBrainsMono`](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304)
release. The font is licensed under SIL Open Font License 1.1; the complete
license is stored beside these files as `OFL.txt`, with one trailing space
normalized to the repository whitespace policy.
